# Logistics and Supply Chain Intelligence Portfolio

Hi, I'm **Kevin Odhiambo Otieno**, based in **Nairobi, Kenya**. I have a **Bachelor of Commerce in Logistics and Supply Chain Management** and hands-on experience in procurement validation, commercial operations and enterprise data workflows.

This repo covers supply chain resilience, sustainable procurement under cost, risk and carbon constraints, and trade performance analytics.

---

## Supply Chain and Technical Capabilities

* **Supply chain and procurement:** Multi-tier supplier risk scoring, lead-time and disruption analysis, sustainable sourcing trade-offs and trade corridor analytics.
* **Data and decision stack:** SQL (SQL Server, DuckDB), Power Query and DAX, Python (`pandas`, simulation and optimization) and interactive BI/Streamlit apps.

## Project Folder Structure

Every project in this repo uses the same layout.

```text
0X-Supply-Chain-Project/
├── dataset/      # Raw and cleaned data, plus a data dictionary
├── sql/          # Schema definitions, views and analytical queries
├── python/       # Scoring, simulation and optimization scripts
├── bi-app/       # Power BI (.pbix), DAX notes or Streamlit apps
├── images/       # Dashboard and simulation screenshots
└── README.md     # Problem statement, stack, data sources, metrics and stretch goals
```
